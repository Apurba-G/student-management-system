# Student Management System - Database Configuration

This folder maintains PostgreSQL container definitions, backup/restore scripts, ER diagrams, and environment files.

## Stack
- **Database**: PostgreSQL 16
- **Database Administration**: pgAdmin 4
- **ORM / Migrations**: Hibernate / Spring Data JPA / Flyway

## Quickstart
\`\`\`bash
# Start database container
docker compose up -d

# Stop database
docker compose down
\`\`\`
