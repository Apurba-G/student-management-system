# Student Management System - Frontend

Angular 18/21 modern frontend application for Student Management System.

## Architecture & Features
- **Core**: Services (\ApiService\, \AuthService\, \NotificationService\), Route Guards, HTTP Interceptors, Global Models.
- **Features**:
  - \uth\: Login interface and authentication state.
  - \dashboard\: System metrics overview, quick analytics, recent registrations.
  - \students\: Comprehensive CRUD operations with paginated tables, search filtering, reactive forms, and detail view.
- **Shared**: Reusable UI components (\LoadingSpinner\, \ConfirmationDialog\, \EmptyState\), Directives, and Pipes.
